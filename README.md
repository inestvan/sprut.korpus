# SPRUT — корпус изделия (10.1" монитор + Raspberry Pi 4B)

Печать: **Creality K2 Plus, PETG**. Модель параметрическая (OpenSCAD), все размеры
компонентов вынесены в начало файла `cad/sprut_korpus.scad`.

| Файл | Что это |
|---|---|
| `cad/sprut_korpus.scad` | исходник модели, параметры в начале файла |
| `stl/sprut_box.stl` | коробка (задняя стенка + борта), печатать как есть |
| `stl/sprut_bezel.stl` | лицевая рамка, уже развёрнута лицом вниз |
| `preview/*.png` | рендеры для проверки |
| `docs/components.md` | размеры компонентов, источники, что нужно проверить |

Наружный габарит при параметрах по умолчанию: **263 x 151 x 50 мм** (Ш x В x Г).
Оба STL помещаются на стол K2 Plus (350 x 350) одновременно.

## Конструкция

Две детали, монитор загружается **спереди**:

1. **Коробка** — открыта спереди. На задней стенке: 4 стойки Raspberry Pi
   (M2.5), два держателя-«кармана» для DC-DC и RS485 (плата вдвигается в пазы),
   вентиляционные щели, отверстия VESA 100 (M4). В нижнем борту: вырез
   XT60E-M с двумя отверстиями под винты, отверстие BNC, окно RJ45, окно
   портов Pi (2xUSB2 + 2xUSB3 + Ethernet). В верхнем борту — вентиляция.
   По левому и правому краю — каналы шириной 8 мм с шестью бобышками под
   резьбовые вставки M3. Внутренние стенки каналов и полки по длинным
   бортам держат монитор на нужной глубине.
2. **Лицевая рамка** — 3 мм, окно экрана с фаской 45°, 6 винтов M3 с потаем.

Порядок сборки: вставки M3 в бобышки (паяльник) → Pi на стойки (торцом USB к
нижнему борту, компонентами к экрану) → DC-DC и RS485 вдвинуть в держатели →
XT60/BNC/RJ45 в нижний борт → монитор положить спереди на полки (по периметру
рекомендую двусторонний вспененный скотч 1 мм) → рамка на 6 винтов M3x8.

## Что обязательно проверить перед печатью

Полный список с размерами и источниками — в `docs/components.md`. Коротко:

- **Монитор.** Страница Ozon из среды сборки не открылась (антибот блокирует
  любой запрос, включая браузер). В модели стоит типовой габарит панели 10.1"
  1024x600: 235 x 143 x 5.5 мм, активная область 222.7 x 125.3. Замерь свой
  и поправь `mon_w, mon_h, mon_t, view_w, view_h, view_dx, view_dy`.
  Если монитор в собственном корпусе (готовый портативный монитор), нужен
  другой подход — напиши, переделаю под встраивание целиком.
- **DC-DC 60V/3A (CR-6030L).** Точных размеров в сети нет; по фото и листингу
  ~43 x 21 мм, высота ~14 мм с конденсаторами. Держатель параметрический
  (`dcdc_l, dcdc_w`), подстрой под замер.
- **RS485-TTL.** 34 x 18 x 9 мм (с фото продавца) — заложено.
- **RJ45.** Гнездо на фото — под пайку в плату (8P8C, 15.9 x 21.6 x 13.4).
  Заложено окно 16.8 x 14.3 мм; само гнездо нужно припаять на плату и
  закрепить у стенки. Если возьмёшь панельный RJ45 (keystone / проходной с
  фланцем), скажи — заменю вырез.
- **BNC.** Заложено круглое отверстие Ø9.9 под резьбу 3/8"-32. Если у твоего
  разъёма есть лыска против проворота, поставь `bnc_flat = 9.0` (D-отверстие).

## Печать (K2 Plus, PETG)

- Сопло 0.4, слой 0.2, стенки 4 периметра (1.6 мм), верх/низ 5 слоёв,
  заполнение 25–30 % gyroid.
- Коробка — задней стенкой вниз (как в STL), **без поддержек**: стойки,
  бобышки и держатели вертикальные, полки под монитор с фаской 45°, окна в
  бортах перекрываются мостами до 55 мм (окно портов Pi) — для PETG
  включи охлаждение мостов.
- Рамка — лицом вниз (как в STL), без поддержек. Для гладкого лица —
  гладкий PEI лист. Потай под винты печатается конусом вверх.
- Резьбовые вставки M3 (OD 4.5–4.6, длина 5–6): отверстие 4.0 мм.
  Саморезы Pi M2.5 в отверстие 2.2 мм. XT60 — саморезы M3 в отверстие 2.5 мм
  (или поставь `xt_screw_d = 3.2` под болт с гайкой).
- Температура сопла PETG 240–250 °C, стол 75–80 °C, клей/лак на стол,
  дверь принтера закрыть.

## Крепёж

| Винт M3x8 потайной | 6 |

## Регенерация STL

```bash
openscad -o stl/sprut_box.stl   -D 'part="box"'   cad/sprut_korpus.scad
openscad -o stl/sprut_bezel.stl -D 'part="bezel"' cad/sprut_korpus.scad
```
